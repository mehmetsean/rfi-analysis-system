# Data

All data in this repo is synthetic.

- examples/ is written by scripts/make_examples.py from seed 42 (200 synthetic RFIs).
- heldout/ is written by hand for this repo. heldout/manifest.json has "synthetic": true.
- Generated output (src/rfikit/synth) is made from seeds.
- No real RFI, project, company or person is used.

The designation catalog, templates, phrase lists and stop words are written for this repo. No outside list is used.
